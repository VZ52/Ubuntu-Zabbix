# Ubuntu-Zabbix
  Стенд мониторинга на базе Zabbix 7, разворачиваемый одной командой через Docker Compose.
  Pet-версия мониторинга, который я разворачивал на работе (сеть медицинских клиник «Тонус»),
  с доведённым до конца Telegram-алертингом.

 ## Стек

  - Ubuntu Server (host)
  - Docker, Docker Compose
  - Zabbix Server 7.x, Zabbix Web (nginx), Zabbix Agent2
  - PostgreSQL 15
  - Python (Telegram-алертинг)
